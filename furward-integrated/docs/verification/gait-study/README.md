# 人物步频候选与采用证据

已采用中栏 **0.68 米参数、脚掌滚动** 版本。三栏图片和视频按 **左：原 0.42；中：采用 0.68；右：未采用 0.70** 排列。0.70 的 GLB 不进入生产资源；对照文件只保留评审证据。

`stride_m` 是脚在支撑阶段相对身体的前后行程，不能直接当作现实中的单步长度。两版原地 walk 的资源周期均为 1.2 秒，支撑占比均为 0.62；路线仍以 1.2 米/秒行进。

| 指标 | 原版 | 采用版 |
|---|---:|---:|
| 脚的局部支撑行程 | 0.42 m | 0.68 m |
| 标称速度 | 0.564516 m/s | 0.913978 m/s |
| 路线实际动画周期 | 0.564516 s | 0.913978 s |
| 路线步频 | 212.6 步/分 | 131.3 步/分 |
| 现实单步前进距离 | 0.3387 m | 0.5484 m |
| 额外髋部下沉 | 0 | 4 mm |
| 脚掌世界俯仰范围 | 0° | 脚尖上翘22°／蹬地20° |
| 最大膝弯（721相位） | 66.1° | 67.9° |
| 最大大腿偏离竖直 | 39.1° | 45.5° |

直接扩大步幅会超出腿骨可达范围；采用版根据原鞋底最低接触顶点补偿踝关节高度和前后位置，使脚跟落地、脚尖蹬地时仍按路线速度标定。100001相位独立检查无目标越界，扣除IK安全量后最小余量1.4414毫米。

人物原位置、法线、UV、索引、材质、贴图、骨骼、权重全部保留；仅 `walk` 动画变化，idle/turn_left/turn_right/stop 逐轨道数值与原版相同。机器狗GLB逐字节保持不变。正式脚本为 `scripts/rig-models.py`。

## 可见效果和限制

逐帧检查了侧面落脚、摆腿、正面单脚支撑、37.5%相位停车0.1秒和城市跟随。采用版的脚掌滚动可见、步频降低，裤裆没有新增明显尖刺，膝部仍有低多边形折线。裤裆一条原长5.831厘米的边由原版最大全长约11.892厘米变为13.246厘米；这来自原有权重牵拉，不能宣称布料模拟质量。高倍近景仍受原网格限制。

实际Three.js、最终蒙皮、路线1.2米/秒下，支撑接触顶点水平残速平均0.0066米/秒，P95 0.0374米/秒；原版平均0.00085。脚掌滚动的插值带来小幅残速，不是绝对零滑步。测试排除了支点身份切换，并只追踪近地且稳定支撑的同一顶点。

正式过渡回归覆盖768组相位/动作/地面/帧率与240次常量轨道恢复；结果以 `web/public/city/animated/transition-validation.json` 为准。几何、UV、贴图保存与单动作结果以同目录 `validation.json` 为准。
