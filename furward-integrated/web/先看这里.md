# 绒途 Furward｜首页三段动效版

交付日期：2026-10-25。此包是完整项目源码和内置图片，已包含本次首页动画修改，尚未部署到原公网网站。

## 打开项目

1. 解压 ZIP，进入 lando-studio 文件夹。
2. 安装 Node.js 24；本包不包含 node_modules，首次启动需要网络下载依赖。
3. Mac 用户可双击「启动网站.command」，按提示设置自己的后台密码并保持终端窗口打开。启动后打开 http://localhost:3000/ 查看首页；http://localhost:3000/admin 是换图后台。
4. 也可以在该文件夹的终端执行：

```sh
npm ci
npm run setup:admin
npm run dev:selfhost -- --port 3000
```

## 这次修改

首页先显示拉布拉多。点击「播放演示」，约 6 秒连续经过流动视角并停在机器狗；支持暂停、继续和重播。三个旧切换按钮已改为播放阶段提示，菜单中的「首页演示」只返回首屏。后台的换图、叠加对齐与流动预览继续保留。
