# 城市 + 盲人 + 机械狗：网页资产交接 V10

直接把整个压缩包交给网页开发者。本包是场景/模型/碰撞数据交付，不是已实现人物行走、导盲行为或动画的网页。

## 文件与加载顺序

1. `assets/city_visual_v08.glb`：原城市视觉，保持原文件字节不变。
2. `assets/city_periphery_v10.glb`：新增外围背景景观，与原城市使用同一世界坐标，直接叠加。
3. `assets/characters_placed_v10.glb`：已落地、已摆放的人物与机械狗，用于快速查看整合效果。
4. `assets/city_collision_v09.glb` + `assets/collision_manifest.json`：原 160 个静态碰撞代理与定义。不要把碰撞模型加入正式可见场景。
5. `source/City_Integrated_v10.blend`：可继续编辑的完整工程，原碰撞、原相机、原资产保留。
6. `scene_manifest.json`：出生点、朝向、尺寸、原相机与光照参考。

所有城市资产均为米制、glTF Y-up；必须原坐标加载，禁止分别居中、缩放或再次 Z-up 转换。原点距城市有偏移属于已有坐标设计。

## 角色接入

- 独立角色：`blind_person.glb` 与 `robot_dog.glb`。脚底为原点，规范朝向为 glTF **+Z**，人物高 1.80m，机械狗高 0.90m。
- 用独立角色时，按 `scene_manifest.json → spawn` 的 `position_gltf` 与 `yaw_gltf_rad` 设置各自根节点。
- **独立角色和 characters_placed 只选一种加载，避免重复。**
- 根节点：`BlindPerson_Root`、`RobotDog_Root`；可分别交给控制器驱动。
- 本次采用用户提供的贴图版“人物+角色.blend”，不是文件夹里旧的程序化示例。未重建模型外观。
- 当前均为静态网格，无骨骼、蒙皮、IK、动作片段或牵引绳。可以展示及整体移动；走路、关节动画和人与狗协作控制仍需开发/绑定制作。
- 出生点已通过地面碰撞网格射线确认有支撑；这是静态摆放验证，未代替角色控制器通行测试。

## 城市与碰撞边界

原 538 个对象及 160 个代理保留。新增 15 栋背景建筑、42 棵树、28 个灌木、6 张长椅与成组绿化放在原碰撞边界之外，用于丰富四周天际线与街区层次。

**外围是不可到达的背景景观，不是新增可玩区域。** 原四面边界墙继续有效，新增景观无需新碰撞，不会在原通道生成隐形阻挡。如后续要走入外围，需另行扩展地面和边界碰撞，不能直接移除现有边界墙后发布。

碰撞清单中的 `cuboid` 使用 `halfExtents`；`convexHull` 使用局部顶点配合 position/rotation；`trimesh` 从碰撞 GLB 对应节点读取并应用 matrixWorld。坐标不要应用两遍。详见 `docs/碰撞交付说明.txt`。

`integration.mjs` 是供已有 Three.js / Rapier 项目调用的最小资产接线模块，不包含页面、人物移动或游戏循环。它使用开发项目已安装的依赖，不引入 CDN。

## 外观与性能

- 原城市视觉 GLB 不重新导出；新增资产共享原有材质和网格，简单低多边形风格。
- GLB 中的材质可直接加载；Blender 的世界光照、AgX 色彩管理和阴影不会自动变成网页设置。请以 `scene_manifest.json` 的原光照/相机数据作参考，再在网页实现。
- 角色贴图内嵌，不依赖原电脑的 Downloads 路径。保留现有纹理分辨率；可按网页性能预算后续压缩 KTX2。
- 摄像机数据是原相机参考，不表示自动追踪角色；开发者自行决定运行时取景。

## 验证与限制

检查结果见 `validation_report.json`：原核心文件校验和、GLB 内嵌资源、角色尺寸/朝向数据、动画/骨骼状态和原对象保留检查。

源城市报告由 Blender 5.4.3 生成，本机 5.2.3 打开时提示可能丢失新版本特性。为避免影响网页核心资产，本包直接沿用原始核心视觉/碰撞 GLB；新整合 .blend 已确认原对象数量与网格/变换/材质绑定/可见性保持一致，但这不是跨版本所有功能的全面兼容认证。

地图外围为根据所给截图的示意性补充，非测绘复刻。共享聊天链接未能读取，采用了本地说明与实际资产。详细来源与许可证见 `docs/PROVENANCE.md`。
